# ADR 0004 — OS만 있는 VM에서 한 번 실행으로 설치

- 날짜: 2026-11-07
- 상태: 채택, 실제 VM 검증 대기
- 근거: 사용자는 Docker 등을 수동으로 준비하는 절차 대신 설치 프로그램이 sudo 권한으로 필요한 작업을 끝내도록 요구했다.

## 결정

사용자 진입점은 `sudo bash install.sh`다. 기본 의존성·Docker/Compose·Python venv·저장 경로·커널 모듈·설치 계획·이미지 빌드·기동·수용 검증·부팅 등록을 설치기가 수행한다. 문서의 수동 Docker 설치는 개발자 조사 절차로만 남긴다.

모듈 선택은 기존 manifest와 plan 계약을 사용한다. 미구현 모듈은 조용히 건너뛰지 않는다. 현재 기본 프로필은 experimental security-path와 검증용 fixture이며, 전체 Community 제품의 완료와 구별해 상태를 기록한다.

Docker·containerd 저장소를 함께 구성하고, 기존 타 서비스나 런타임 데이터를 삭제·자동 이관하지 않는다. 전용 VM만 허용한다. 비밀정보를 릴리스 소스에 복사하지 않으며 실행 로그와 상태는 root 전용으로 저장한다.

성공 조건은 실제 통신·차단·우회 방지·출처 보존·IPS 재시작 복구 검사의 통과다. 명령 종료 코드와 상태 파일은 이를 반영한다. 부팅 서비스는 기존 검증 계획·로컬 이미지를 사용하며 재부팅 때 빌드나 이미지 갱신을 하지 않는다.

## 후속 범위

공식 릴리스의 서명·digest 고정, 전체 Core 모듈, 디스크 자동 준비, 제품 업그레이드와 rollback은 별도 구현한다. 현재 자동 설치 코드를 작성했다는 사실을 빈 VM 설치 검증 통과로 취급하지 않는다.
