# ADR 0010: 시설 표시와 네트워크 장비는 Core, 시설 시뮬레이터·장애 주입은 M4, 중앙 주입은 Range Control

- 상태: 소유자 결정, 2026-11-15
- 바꾸는 것: [DATACENTER](../development/DATACENTER.md)의 "B1 전력·냉각 설비 = Live Fire 이상, M4" 층 표, CLAUDE.md의 "시설·주입기(M4)는 Core에 포함하지 않는다"의 범위
- 관계: 정본 `xocrange_plan` MODULES의 M4(시설·장애, Live Fire)와 PACKAGING의 C3(공격→시설 매핑)는 그대로다. 이 ADR은 **표시**와 **실행**의 경계만 정한다.

## 배경

- Core는 kt66의 데이터센터 화면을 상속했지만 시설(B1 전력·냉각, 옥외 설비)은 잠겨 있었다. 학생은 전산실(2F)의 장비만 보고 그 장비를 지탱하는 전력·냉각 계통을 볼 수 없었다.
- kt66에는 시설 대장(`envsim/assets.yaml`, 시설 약 60개)과 종류별 교육용 설명(`envsim/facility-guide.yaml`, 39종), 물리 시뮬레이터(`envsim/model.py`), 장애 주입기(`injector`)가 있다.
- 실습망은 Docker 브리지 4개(ext·pipe·dmz·int)와 그 사이를 잇는 fw·ips로 동작한다. 이 브리지와 라우팅이 화면에 없어서 학생이 토폴로지를 혼동했다.

## 결정

1. **Core(Community) — 시설 표시.** B1과 옥외 설비를 Community에서 연다. 시설을 고르면 설명(역할·배치·영향·점검 항목)과 상태를 보여 준다. M4가 없으면 상태는 **기준값**(대장의 정격·설정값, "시뮬레이터 없음")이다. Core는 시설 물리를 계산하지 않고, 장애를 만들지 않는다.
2. **M4 시설·장애 모듈(Live Fire) — 시뮬레이터와 주입기.** 시설 상태를 계산하는 시뮬레이터와 장애 주입기는 C7 승인이 있을 때만 설치되는 모듈이다. 처음 범위는 **시뮬레이션만**이다: 장애는 시설 상태 값을 바꿀 뿐 컨테이너·네트워크·호스트에 실제 영향을 주지 않는다. 장애 종류는 정해진 목록(kt66 시나리오 기반)만, 모든 장애는 시간이 지나면 자동 복구되고, 주입·복구는 감사 기록에 남는다.
3. **상태 전달 계약.** M4는 시설 상태를 정해진 스키마(`xoc.facility-state/0.1.0`, 자산 ID·상태·측정값·활성 장애)로 Core에 넘긴다. Core는 스키마와 자산 ID를 검증한 값만 화면에 쓴다. 스키마는 M4 구현 때 Core `contracts/`에 추가한다.
4. **장애 주입 경로.**
   - 학생: 자기 Core의 M4 화면에서 자기 데이터센터에 주입한다.
   - 강사(중앙): Range Control에서 등록된 레인지 하나·여러 개·전체를 골라 주입한다. 판정기(Assessor)와 같은 방식으로 Core 쪽 모듈이 Range Control에 먼저 연결해 작업을 받아 간다. Core에 새로 열리는 포트는 없다.
   - 공격 성공→시설 장애(C3)는 이 주입 경로 위에 나중에 붙인다.
5. **Core(Community) — 네트워크 장비 표시.** 2F에 실습망 스위치 4대(ext·pipe·dmz·int = 실제 Docker 브리지)와 구간을 잇는 라우터 역할(fw: ext↔pipe, ips: pipe↔dmz, web: dmz↔int)을 장비로 보여 준다. 상태·주소·연결된 장비·트래픽 수치, 읽기 전용 라우팅 표·ARP·MAC 주소 표는 호스트 관측기가 고정된 읽기 명령으로 수집해 플랫폼에 넘긴다. 웹 프로세스는 Docker 소켓을 받지 않는다(기존 원칙). 실제 라우터·스위치 장비(FRR·Open vSwitch)를 넣는 것은 이 ADR의 범위가 아니다.

## 결과

- CLAUDE.md 규칙은 "시설 **시뮬레이터**·장애 주입기(M4)는 Core에 포함하지 않는다. 시설 표시와 기준값은 Core(ADR 0010)"로 바뀐다.
- Core 화면이 보여 주는 시설 상태는 M4 없이 항상 기준값이므로, 장애가 없다는 뜻으로 오해하지 않게 "시뮬레이터 없음"을 함께 표시한다.
- 네트워크 장비 표시는 0.1.0에서 검증한 데이터 경로를 바꾸지 않는다. 관측값만 늘어난다.
- 시설 대장·설명은 kt66 자산을 기능 단위로 옮기고 출처를 `docs/provenance/`에 남긴다.
