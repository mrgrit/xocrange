# ADR-0002: 첫 구현의 계약·패키지·실행 경계

상태: 2026-11-07 초기 구현에 적용. 상위 기준은 [ADR-0001](0001-core-boundaries.md)과 계획 저장소 `5599078`이다.

## 결정

1. Python `src/xocrange` 패키지에 오프라인 CLI·C1 어댑터·검증·계획기를 둔다. 현재 개발 호스트의 Python 3.10을 기준으로 검증하고 CI에 3.10/3.12를 선언한다.
2. JSON Schema Draft 7을 패키지 데이터로 제공한다. 검증할 때 외부 스키마를 가져오지 않는다. 실제 발생 시각과 수집 시각, 신뢰된 수집 컨텍스트, 원본 참조를 분리한다.
3. 설치 구성요소는 `components/`, 확장은 `modules.d/`, 테스트 확장은 `tests/fixtures/modules/`에 둔다. 단일 manifest 계약을 공유하며 Core 공통 코드에 확장 구현을 복사하지 않는다.
4. `security-path`는 fw·ips·web·라우팅을 포함하는 첫 이식 단위다. 경로 보장 전에는 서비스를 독립적으로 제거할 수 있다고 약속하지 않는다. SIEM·각 장비 콘솔·타깃·SSH·portal·NOC·자료 열람은 별도 선택 단위다.
5. 먼저 부작용 없는 `plan`·`doctor`를 구현한다. 실행 가능한 bootstrap과 아직 계획인 Community 기능을 상태로 구분한다. 설치 실행, 네트워크 권한, 롤백·복원은 후속 단계다.
6. C7이 구현되기 전에는 유료 모듈 계획을 거부한다. 이 정책은 상용 entitlement 검증 구현을 대신하지 않는다.

## 결과와 남은 일

실제 운영 스택 없이 계약·실패 동작·선택 조합을 개발할 수 있다. 첫 구현에서는 방화벽·라우팅·상태 저장 SIEM의 권한을 허용하지 않았다. 이후 [ADR-0003](0003-security-path-and-host.md)에 따라 보안 경로에 한정한 실험 프로필을 추가했으며 격리된 VM 검증을 기다리고 있다. K06의 저장소 정책 확장은 별도 작업이다.

컨테이너·패키지 의존성을 고정한 배포 lock, 실제 지원 OS/리소스, 상용 라이선스 검증, 배포 권리 검토는 완료되지 않았다. Python 배포 패키지는 CLI와 스키마이며 전체 설치 자료는 소스 체크아웃을 함께 사용한다.
