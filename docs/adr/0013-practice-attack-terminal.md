# ADR 0013: 외부망의 공격 실습 단말

상태: 구현·실행 검증(2026-11-18, 두 번째 Core 192.168.16.51). Core에 둘지는 소유자 확인을 기다리는 항목이다
([전환 계획](../development/CONTENT-PORTING-PLAN.md) 3장 3번).

## 배경

Community 번들의 교재는 공격 명령을 "공격자 단말"에서 실행한다. 이전 인프라(kt66 `9b3efed`)에는
외부망 `ext`에 `attacker` 컨테이너(10.20.30.202, 호스트 포트 2202 → 22)가 있었다. 현재 Core에는 없다.
조사 결과([목록](../development/content-ledger/)) 이 단말이 없어 생기는 차이는 다음과 같다.

- 도구: 교재는 hydra·sqlmap·nikto·gobuster·dirb·nmap을 쓴다(01, 04, 06, 14, 16~18, 30번).
- 출발지 주소: 외부에서 2222로 들어온 SSH는 업무용 PC에 진입점 주소(10.20.30.20) 하나로 보인다.
  교재의 SSH 사례는 `data.srcip`로 공격자를 가려낸다(16~19번).
- 업무 호스트에서 공격자 쪽으로 나가는 실습(25, 26번)과 방화벽을 지나는 포트 스캔(30번)의 상대.

## 결정(안)

1. **`attacker` 컴포넌트를 Core(Community)에 둔다.** 외부망 10.20.30.202(kt66과 같은 주소), 외부망에만
   연결한다. 교재가 쓰는 도구와 SSH 서버만 있고, 수집·채점·대전 실행 기능은 없다(M15 경계 유지).
   Live Fire의 공격자 VM·에이전트(L09)와는 별개다.
2. **접속:** 호스트 포트 2202 → 진입점 → 단말의 SSH. 계정은 업무용 PC와 같은 실습 계정이다
   (`sudo xoc platform credentials`).
3. **실습망으로 가는 길은 방화벽뿐이다.** 단말의 기본 경로는 방화벽(10.20.30.1)이다.
   - 웹: `http://dvwa.xoc.range/` → 방화벽 80 → IPS → 웹 방화벽 8080. 단말의 hosts 파일이 학습자
     이름을 방화벽 주소로 풀고, 웹 방화벽의 8080 가상 호스트가 학습자 이름에도 응답한다. 접근 로그의
     출발지는 단말의 주소다.
   - 업무용 PC SSH: `ssh -p 2222 student@10.20.30.1`. `auth.log`와 경보의 출발지가 10.20.30.202로 남는다.
4. **업무용 PC → 단말은 실습 포트 둘(4444, 8000)만 연다.** 방화벽 기록과 IPS 검사를 거친다.
5. 단말의 세션은 NET_ADMIN 없이 돈다. 포트 스캔을 위해 NET_RAW는 남긴다. 외부망은 인터넷으로 나가지
   않으므로 단말에서 실습망 밖을 공격할 수 없다.

## 실행 검증 (2026-11-18, 192.168.16.51)

외부에서 `ssh -p 2202 student@192.168.16.51`로 단말에 들어가 실행했다.

| 항목 | 결과 |
|---|---|
| 단말의 경로·이름 | 기본 경로 10.20.30.1, hosts에 `dvwa.xoc.range`·`dvwa.bob.lab` |
| `curl http://dvwa.xoc.range/` | 302(DVWA 로그인으로 이동) |
| UNION SELECT 요청 | 403(웹 방화벽 차단) |
| 인터넷·내부망 직접 | 연결 불가 |
| `hydra -l student -P <틀린 암호 10개> ssh://10.20.30.1:2222` | 유효 암호 0. 경보 5760 ×9, 5763 ×1, `data.srcip` 10.20.30.202 |
| 자동 차단 | 업무용 PC에 `-A INPUT -s 10.20.30.202/32 -j DROP`, 이어진 SSH는 시간 초과. 180초 뒤 규칙 삭제 |
| `nmap -sT -p 22,80,2222,8080,3306 10.20.30.1` | 80·8080 open, 나머지 filtered |
| 업무용 PC → 단말 8000 | 200, 방화벽 기록 `SRC=10.20.70.21 DST=10.20.30.202 DPT=8000` |
| 업무용 PC → 단말 9000 | 연결 불가 |

아직 검증하지 않은 것: sqlmap·nikto·gobuster·dirb의 실제 실행, 4444 포트, 학생 도메인이 없는 Core.

## 영향

- 게시 포트가 하나 늘어난다(2202). 관리용 진입점(HAProxy)이 TCP로 넘긴다.
- 기본 설치에 포함하고 `--without attacker`로 뺄 수 있다. 기존 설치본은 `sudo xoc module add attacker`.
- 2F 화면의 외부망 스위치에 장비가 하나 늘어난다.
