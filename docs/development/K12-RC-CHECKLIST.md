# K12 Community RC 체크리스트

정본: [CORE-KICKOFF §7 G1](https://github.com/mrgrit/xocrange_plan/blob/f548caa/docs/CORE-KICKOFF.md). 이 문서는 G1의 각 증거 항목에 대해 **지금까지 있는 실행 증거**와 **RC 판정 전에 남은 일**을 정리한다(작성 2026-11-13, 갱신 2026-11-13 밤, 기준 커밋 `5e38777` → 갱신 시 설치본 `0d3140b`).

## 판정 원칙

- RC 증거는 **하나로 고정한 후보 커밋**에서 다시 실행한 결과만 센다. 아래 "기존 증거"는 이전 소스의 결과이며, 그 항목이 실행 가능하다는 근거일 뿐 RC 증거가 아니다.
- "코드 존재"와 "실행 검증"을 구분한다. 단위 테스트만 있는 항목은 실행 검증으로 세지 않는다.
- 이 VM(Claude Code가 실행 중인 개발 VM)에서는 재부팅·빈 OS 설치를 할 수 없다. 해당 항목은 별도 VM이나 사용자 조작이 필요하다.

상태: **있음**(이전 소스로 실행 검증, RC 후보로 재실행만 필요) · **부분**(일부 조합·조건만 검증) · **없음**(실행 증거 없음) · **결정 필요**(기술 검증이 아니라 소유자 결정)

## RC를 막는 항목

실행 증거가 없거나 소유자 결정이 필요한 항목이다. 나머지는 RC 후보로 재실행하면 된다.

1. 기본 전체 구성의 빈 VM 한 번 설치 (별도 VM 필요)
2. RC 후보 재부팅 검증 (이 VM 재부팅 또는 별도 VM)
3. 외부 PC 출처 IP 보존 — 모의 외부 클라이언트로 보존 확인(2026-11-13). 실제 외부 PC 확인만 남음
4. ~~배포물 경계 자동 점검 스크립트~~ — 작성·실행 완료(2026-11-13), RC 후보에서 재실행
5. 전체 디스크 고갈 시험과 24시간 이상 장기 운영 기록
6. ~~동시 apply 시험~~ — broker·Core HTTPS 수준 모두 통과(2026-11-13), RC 후보에서 재실행
7. 선택 조합 보완: ~~`console-fw`·`console-waf` 개별 제외~~(2026-11-13 통과), "전체 Community"·bootstrap·기본 타깃 제외의 범위 정의
8. Core 배포 라이선스·프로젝트 자산 배포 권리 결정 (소유자)
9. 릴리스 노트·사용자 안내·SIEM 포함 권장 사양
10. 로그인 제한이 성공한 로그인도 세는 정책(계정당 15분 10회)을 유지할지 결정 (소유자)

## 로그인이 필요한 검증

관리자 비밀번호가 초기값에서 바뀐 설치본에서는 `XOC_ADMIN_PASSWORD_FILE`에 권한 600 파일 경로를 주면 통합 시험이 그 파일에서 비밀번호를 읽는다(`tests/integration/admin_credential.py`). 지정하지 않으면 `credentials.json`의 `admin_password`(없으면 초기 비밀번호)를 쓴다. 비밀번호를 명령 인자나 셸 명령에 넣지 않는다(Sysmon이 명령줄을 SIEM 저장소에 기록). 계정당 로그인 제한(15분 10회, 성공 포함) 때문에 시험을 연달아 돌리면 429가 날 수 있다.

2026-11-13 이 방식으로 로그인이 필요한 시험을 모두 실행했다([결과](RETENTION-ADDRESS-PLAN-2026-11-13.md#5-로그인이-필요한-시험)).
