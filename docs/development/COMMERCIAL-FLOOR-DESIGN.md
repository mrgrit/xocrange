# 아카데미 · Live Fire · Agent Office 디자인

2026-11-08 사용자 피드백을 반영했다. Core 운영 기능은 유지하면서 admin에게 상용 층 확대 공간과 화면 구성을 제공한다. 디자인 데이터는 Core에 포함된 정적 예시다. 카탈로그 검색·분류·상세와 미션 화면 선택은 브라우저 안에서 동작하며 콘텐츠 공급·훈련 실행·채점·AI 호출을 수행하지 않는다.

## 공간과 화면

- **6F 아카데미:** 책상·학생 좌석을 제거하고 부유형 투명 썸네일과 유리 터치 테이블으로 구성했다. `화면 구성`에서 6종 예시 카탈로그를 검색·분류하고 상세의 강의·실습·워크북을 선택한다. 상용 연결 시 기관이 구매한 콘텐츠만 서버에서 공급한다.
- **7F Live Fire:** 단좌 조종석 하나, Red/Blue 측면 콘솔, 투명 랩어라운드 HUD와 부유형 시나리오·훈련 정보 패널을 배치했다. `화면 구성`은 브리핑·미션·개인 레벨·과정 진척·리더보드·AI 피드백으로 구성한다. 훈련 시작·근거 제출·힌트는 비활성이다.
- **8F Agent Office:** 오른쪽 큐브를 제거하고 운영 사무실 형태의 24U 랙을 배치했다. 직원 3명과 운영 리드 1명을 두며 Joint Force 회사 생성·에이전트 실행은 후속 구현이다.

## tw2 참조와 후속 연결

참고 저장소: [mrgrit/tw2](https://github.com/mrgrit/tw2), 로컬 체크아웃 `324d91fb22fee2c76051d5e73b58aa7f82de3e4c`. 파일별 해시는 [참조 기록](../provenance/floor-design-source.json)에 있다.

| 화면 | tw2의 참조 기능 | 후속 상용 연결 |
|---|---|---|
| 시나리오·모드 | 시나리오 카탈로그, SOLO/DUEL/FFA, Red/Blue | C7 기관 구매 권한 + M15 실행 승인 |
| 미션 수행 | 역할별 단계, 이벤트 제출, 힌트, Assessor 검증 | M15 대상 환경·증거·판정 API |
| 과정별 진척도 | 개인 과정·미션 진행과 활동 기록 | 기관·사용자별 학습 기록 |
| 리더보드 | 전체·배틀·코호트별 순위 | 범위별 서버 조회·권한 |
| AI 피드백 | 진행 정체·완료·요청 기반 피드백과 활동 근거 | 근거 기반 평가·피드백 서비스 |
| 나의 레벨 | 사용자 추가 요구; 확인한 tw2에는 XP/레벨 모델 없음 | 레벨·경험치 기준 정의 후 연결 |
| 아카데미 | 강의·실습·워크북 학습 자료 흐름 | C7 구매 콘텐츠 ID별 공급·열람 |

화면의 점수·레벨·진척도는 `—`로 표시한다. 예시 과정을 구매 목록이나 완료 기록으로 저장하지 않는다. tw2의 사용자·계정·실제 콘텐츠 본문은 가져오지 않았다.

광학 유리 표현은 반투명 그라데이션·모서리 반사·얇은 발광 테두리로 구성하며, 6F는 보라색 디지털 라이브러리, 7F는 청록색 Cyber Combat Range로 구분한다. 전체 배치는 원본의 낮은 시점을 사용하고 바닥 가장자리를 사선으로 겹쳐 공간을 크게 표시한다.
